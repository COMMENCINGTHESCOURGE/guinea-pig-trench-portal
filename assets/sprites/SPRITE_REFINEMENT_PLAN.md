## PHASE 2: BEZIER REFINEMENT (Pixel outlines → smooth curves)

For each cleaned sprite:
1. **Threshold** the alpha to get binary silhouette
2. **Contour trace** — extract the edge pixel chain
3. **RDP simplification** — reduce to key vertices (epsilon tuned per sprite)
4. **Cubic bezier fitting** — smooth curves between vertices
5. **Re-render** at higher resolution from the bezier path
6. **Export** clean alpha PNG at 256x256 and 512x512

This is the pipeline from the Bezier Study notebook — applied to every real sprite.

### Per-sprite bezier parameters:
| Sprite | RDP Epsilon | Notes |
|---|---|---|
| Mecha | 1.0 (tight) | Angular character — preserve sharp corners on helmet, shoulders |
| Aku Mask | 0.8 (very tight) | Intricate detail — crown figures, gorget, tribal patterns |
| Defender | 1.5 (moderate) | Pixel art — smooth the stairstepping but keep the chunky feel |
| Kraken | 0.6 (very tight) | Organic tentacles — bezier curves are perfect for this |
| Geode | 2.0 (loose) | Geometric — the facets should stay sharp, only smooth the edges between |
| Dim Mak | 1.2 | Character detail — hair, clothing folds, weapon |
| Grief Warrior | 1.0 | Painted style — preserve the brushwork feel |
| Void Runner | 1.5 | Hard surface — straight edges with smooth transitions |

## PHASE 3: ANIMATION (Real frame-by-frame, not re-crops)

### Current problem:
The "generated" frames are mostly the same source image re-cropped or slightly shifted.
Real animation needs distinct poses with interpolated in-betweens.

### For each character, generate:
- **idle** (4 frames) — subtle breathing, weight shift
- **walk** (4 frames) — full stride cycle
- **attack** (3 frames) — wind-up, strike, follow-through
- **hit** (3 frames) — impact, recoil, recovery
- **jump** (4 frames) — crouch, launch, apex, land
- **death** (4 frames) — collapse sequence

### Method:
1. Define key poses as bezier-path control point sets
2. **Interpolate between key poses** using bezier blending (same crossbreeding technique from the notebook)
3. Apply per-frame timing using **Dilla Swing easing** — not linear interpolation, bezier-curved timing
4. Each frame rendered from the interpolated bezier path at target resolution
5. Export as individual PNGs + horizontal strip + 4x grid + SpriteBrain manifest

### Animation timing (per the Ashen Prelate lore):
- idle: 0.7s per cycle (matches Vault Compound 7 heartbeat)
- walk: 0.5s per cycle (brisk)
- attack: 0.4s total (wind-up hangs, strike is fast — Dilla swing)
- hit: 0.3s (1.3 seconds of pink — immediate, then recovery)
- death: 1.0s (the smoke goes cold slowly)

## PHASE 4: VARIANT GENERATION (Crossbreeding at bezier level)

### Current variants (generated by `generate_variants.py`):
- Mecha: corrupted, overcharge, stealth
- Aku: frost, nature, void
- Defender: crystal, shadow, volcanic
- Kraken: deep, ghost, toxic

### Upgrade path:
1. Extract bezier paths for each base character
2. **Crossbreed at control-point level** — not pixel palette swap
3. Each variant gets slightly different silhouette proportions:
   - "corrupted" = control points jittered (the happy little mistake)
   - "overcharge" = control points expanded (power scaling)
   - "stealth" = control points compressed (smaller silhouette)
   - "frost" = add crystal protrusions as new bezier segments
   - "volcanic" = roughen curves (increase RDP epsilon, rougher fit)
4. Color variants applied to the bezier-rendered output, not the raw pixels
